Localized into eight languages

GitChop now ships with English, Spanish, French, German, Japanese, Simplified Chinese, Korean, and Brazilian Portuguese. Verb names (pick, reword, edit, squash, fixup, drop) stay in English everywhere — they're the literal git commands and recognizable in any locale. Everything else (buttons, sheet titles, verb explanations, status messages, conflict-sheet copy) translates to the system language.

Accessibility

  • Drag-reorder via VoiceOver and Voice Control. Every commit row carries Move up / Move down actions that surface in VoiceOver's actions rotor and Voice Control's actions menu, so non-mouse users can drive the rebase reorder.
  • Better chip labels. The verb chip announces as "Verb for commit abc1234" with a separate value of "pick" / "reword" / etc., instead of a generic "popup button" read.
  • Diff pane reads as one element with a summary like "Diff. 12 added, 3 removed, across 4 hunks." Line-level navigation stays available for users who want it.
  • Reword amber deepened for higher contrast on white — clears WCAG AA body-text on the row subject and status-line text.

Smaller fixes

  • Open Repo… no longer leaves an empty window behind if you cancel the picker. The window opens once you've actually chosen a repo.
  • "Close Tab" is now "Close Repo" in the File menu, matching the in-app language.
  • System window tabbing disabled. macOS's Show/Hide Tab Bar and Merge All Windows items no longer appear in the Window menu — GitChop's own tab strip is the multi-repo story.
  • Tab strip auto-hides when only one repo is open.
